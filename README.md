# Intelligent-Video-Surveillance-for-Monitoring-Industrial-Safety-Compliance
Real-time industrial safety monitoring system using fine-tuned YOLOv8 for PPE and restricted zone detection (91.6% mAP @ 50 FPS). Integrates CLAHE low-light enhancement, SORT tracking, SQLite event logging, and Gradient Boosting risk forecasting with an interactive Flask web dashboard.
